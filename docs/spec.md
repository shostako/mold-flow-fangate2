# 形状仕様（2026-09-14 図面から読み取り）

図面は 1:1 スケールの PDF なので、寸法はベクタ線分から実寸で拾った（2.8346 pt/mm）。図面そのものはリポに入れない（顧客名入り）。

座標系: 製品長辺エッジ（ランナ側）を y=0、製品側を +y、ランナ側を −y。x は長辺方向、スプルー軸は長辺中央。
builder の格子系は fangate と同じ（ランナが下、製品が上、y は上向き）で、表示は `display_origin_mm()` で製品エッジ y=0 に変換。

## 製品（12.3 インチ プレート）
| 項目 | 既定値 |
|---|---|
| 外形 | 302.26 × 220.6 |
| 額縁 | 幅 20、t=1.0（外周全体） |
| 内側 | 262.26 × 180.6、t=4.0 |

- **圧縮部は内側 t4.0 の矩形だけ**。額縁 t1.0 は圧縮しない（fangate は製品＋タブを圧縮していた。ここが最大の違い）
- 表示原点は額縁の外縁（製品エッジ）。`Geometry.product_mask` は額縁＋内側、`compression_mask` は内側のみ
- 製品体積（解析値）: 額縁 19 314.4 mm³ ＋ 内側 189 456.6 mm³ ＝ **208.77 cm³**

## ランナ（ファン状、製品長辺エッジに直結）
図面の呼称は「ランナ」。ホットランナーのゲート φ3 から、ファン状の冷ランナを経て製品エッジに入る。fangate の「ファンゲート」に相当。

### 平面形状
- 製品エッジで幅 **300**（長辺中央に対して対称。製品幅 302.26 とは別パラメータ）
- 両フランクは直線で、製品エッジ線に対して **14°**（`fan_flank_deg`）。x 方向 1 mm あたり深さ 0.249 mm（1/4.011）
- スプルー軸は製品エッジから **30**（`runner_len_mm`）。軸を中心に **R12**（`runner_end_d_mm` = φ24）の丸端
- フランクは R12 円に **接線ではなく交差**する（交点は軸から ±11.0、深さ 34.6）。フランクを延長した頂点は深さ 37.4 で円の内側なので、
  シルエットは「三角形 ∪ 円」で表せる（クリップ不要）。図面の設計者が何を基準に引いたかは不明、14° が最もよく合う
- 深さ 20（肉厚傾斜の終端）の線が実線で引かれていて、そこでの幅は 139.5（14° から計算すると 139.6）

### 肉厚（断面図、軸上）
| 深さ d（製品エッジからランナ側へ） | 肉厚 |
|---|---|
| 0 〜 1（`runner_edge_flat_mm`） | 1.0（額縁と同厚、`runner_edge_thk_mm`） |
| 1 〜 20（`runner_ramp_end_mm`） | 1.0 → 2.5 の直線傾斜 |
| 20 〜 丸端 | 2.5 均一（`runner_thk_mm`） |

- 井戸ポケットもコールドスラッグも無い（fangate との違い）。丸端まで 2.5 均一
- 肉厚プロファイルは x に依らず深さだけで決まる（円の部分も同じ則）

### ゲート（射出点）
- スプルー軸上に φ3（`gate_d_mm`）。断面図では固定側からの破線で「←ゲート」。ホットランナーのバルブゲートと読む
- Hele-Shaw に縦チャネルは無いので、軸上の φ3 ディスクを Dirichlet τ=0 の射出点にする（fangate のスプルー足 φ6 と同じ扱い）
- ゲートマーカーはこの φ3 円を実寸で 1 個描く

## 肉盗み（▽ フローバランサー、`balancer_on`、fangate v0.5.0 と同型）
- ランナの x 中央に逆三角形の薄肉部。底辺（幅 `balancer_w_mm`）は **製品エッジ線**に置き、頂点はスプルー側、エッジから `balancer_h_mm`
- 内側の厚み `balancer_thk_mm`。塗りは `min(ランナ, 肉盗み)`（切削なので増肉しない）。エッジ側 1 mm の t1.0 平面では自動的に no-op
- 制約: 底辺幅 ≤ 300（エッジでのランナ幅）、高さ ≤ `runner_len − runner_end_d/2`（頂点が丸端の円に入らない）、厚み < `runner_thk_mm`（どこかで実際に削れる）
- 既定 OFF。既定寸法は fangate と同じ（幅 100、高さ 20 → ここでは上限 18 なので既定 15、厚み 1.0）

## fangate から持ち込まなかったもの
旧ゲート／ウイングゲート／タブ（`gate_type`、`tab_*`、`wing_*`、`old_gate_*`）、井戸・コールドスラッグ・スプルーブッシュ（`well_*`、`slug_*`、`sprue_*`）。
図面のランナは 1 種なので builder は 1 形状に絞り、寸法だけパラメータで振れるようにする。
