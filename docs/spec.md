# 形状仕様（2026-09-14 図面から読み取り）

図面は 1:1 スケールの PDF なので、寸法はベクタ線分から実寸で拾った（2.8346 pt/mm）。図面そのものはリポに入れない（顧客名入り）。

座標系: 製品長辺エッジ（ランナ側）を y=0、製品側を +y、ランナ側を −y。x は長辺方向、スプルー軸は長辺中央。
builder の格子系は fangate と同じ（ランナが下、製品が上、y は上向き）で、表示は `display_origin_mm()` で製品エッジ y=0 に変換。

## 製品（12.3 インチ プレート）
| 項目 | 既定値 |
|---|---|
| 外形 | 302.26 × 220.6 |
| 額縁 | 幅 20、t=1.0（外周全体） |
| 内側 | 262.26 × 180.6、t=4.0 |

- **圧縮部は内側 t4.0 の矩形だけ**。額縁 t1.0 は圧縮しない（fangate は製品＋タブを圧縮していた。ここが最大の違い）
- 表示原点は額縁の外縁（製品エッジ）。`Geometry.product_mask` は額縁＋内側、`compression_mask` は内側のみ
- 製品体積（解析値）: 額縁 19 314.4 mm³ ＋ 内側 189 456.6 mm³ ＝ **208.77 cm³**

## ランナ Gate 1（ファン状の逆三角形、製品長辺エッジに直結）
客先図面の形。UI では「Gate 1（逆三角形・客先図面）」。図面の呼称は「ランナ」。ホットランナーのゲート φ3 から、ファン状の冷ランナを経て製品エッジに入る。fangate の「ファンゲート」に相当。

### 平面形状
- 製品エッジで幅 **300**（長辺中央に対して対称。製品幅 302.26 とは別パラメータ）
- 両フランクは直線で、製品エッジ線に対して **14°**（`fan_flank_deg`）。x 方向 1 mm あたり深さ 0.249 mm（1/4.011）
- スプルー軸は製品エッジから **30**（`runner_len_mm`）。軸を中心に **R12**（`runner_end_d_mm` = φ24）の丸端
- フランクは R12 円に **接線ではなく交差**する（交点は軸から ±11.0、深さ 34.6）。フランクを延長した頂点は深さ 37.4 で円の内側なので、
  シルエットは「三角形 ∪ 円」で表せる（クリップ不要）。図面の設計者が何を基準に引いたかは不明、14° が最もよく合う
- 深さ 20（肉厚傾斜の終端）の線が実線で引かれていて、そこでの幅は 139.5（14° から計算すると 139.6）

### 肉厚（断面図、軸上）
| 深さ d（製品エッジからランナ側へ） | 肉厚 |
|---|---|
| 0 〜 1（`runner_edge_flat_mm`） | 1.0（額縁と同厚、`runner_edge_thk_mm`） |
| 1 〜 20（`runner_ramp_end_mm`） | 1.0 → 2.5 の直線傾斜 |
| 20 〜 丸端 | 2.5 均一（`runner_thk_mm`） |

- 井戸ポケットもコールドスラッグも無い（fangate との違い）。丸端まで 2.5 均一
- 肉厚プロファイルは x に依らず深さだけで決まる（円の部分も同じ則）

### ゲート（射出点）
- スプルー軸上に φ3（`gate_d_mm`）。断面図では固定側からの破線で「←ゲート」。ホットランナーのバルブゲートと読む
- Hele-Shaw に縦チャネルは無いので、軸上の φ3 ディスクを Dirichlet τ=0 の射出点にする（fangate のスプルー足 φ6 と同じ扱い）
- ゲートマーカーはこの φ3 円を実寸で 1 個描く

## 肉盗み（▽ フローバランサー、`balancer_on`、fangate v0.5.0 と同型）
- ランナの x 中央に逆三角形の薄肉部。底辺（幅 `balancer_w_mm`）は **製品エッジ線**に置き、頂点はスプルー側、エッジから `balancer_h_mm`
- 内側の厚み `balancer_thk_mm`。塗りは `min(ランナ, 肉盗み)`（切削なので増肉しない）。エッジ側 1 mm の t1.0 平面では自動的に no-op
- 制約: 底辺幅 ≤ 300（エッジでのランナ幅）、高さ ≤ `runner_len − runner_end_d/2`（頂点が丸端の円に入らない）、厚み < `runner_thk_mm`（どこかで実際に削れる）
- 既定 OFF。既定寸法は fangate と同じ（幅 100、高さ 20 → ここでは上限 18 なので既定 15、厚み 1.0）

## ランナ Gate 2（五角形、2026-10-06）
ユーザーの手書きスケッチ（2026-10-06）から起こした形。UI では「Gate 2（五角形・側辺つき）」、`runner_shape = "pentagon"`。
既定値は `GATE2_DEFAULTS`。図面は `docs/draft/gate2_drawing.pdf`（`gate2_drawing.py` が builder の既定値と接点から描く）。

### 平面形状
- 製品エッジで幅 **300**（`runner_w_mm`、Gate 1 と共通）。両端から側辺を真下に **28**（`side_len_mm`）下ろす
- **側辺の長さは額縁の下端（＝製品エッジ）から測る。** 額縁 20 も含めたゲートブロックの側辺は h = 20 + 28 = 48。入力 10 なら h = 30
- 側辺の下端から、スプルー軸の受け（R12、軸は製品エッジから 30）の円の**下側に接する**斜辺を引く。底は二つの接点の間の円弧
  - 接点 (±1.12, 深さ 41.95)、斜辺の傾き 5.35°（側辺と R12 から決まる従属値で、入力ではない）
  - シルエットは「側辺の長方形と円の凸包」。`side_len ≤ runner_len + R`（角が円の下端より深いと斜辺が上向きになる）、角は円の外
  - `side_len = runner_len + R` のとき斜辺は水平になり、長方形 300 × 42
- 肉盗み（▽）は Gate 1 と同じ規則で置ける（頂点は R12 の上端より上）

### 肉厚（深さ d だけで決まる、Gate 1 と共通の規則）
| 範囲 | 肉厚 | 変数 |
|---|---|---|
| エッジ帯 0 〜 幅 | エッジ帯の肉厚 1.0 | `runner_edge_thk_mm`、幅 `runner_edge_flat_mm` = 1（**0 で帯なし**） |
| 傾斜あり: 帯の終わり 〜 d_s | エッジ帯の肉厚 → t_o の直線 | `runner_ramp_on`、d_s = `runner_ramp_end_mm`（既定 None = R12 の上端 30 − 12 = 18） |
| 傾斜あり: d_s 〜 底 | t_o = 2.5（円の外も） | `runner_thk_mm`（「円の外の肉厚 t_o」） |
| 傾斜なし: 帯の終わり 〜 底 | t_o（帯の先で段差） | 同上 |
| 円（R12）の中 | 円の深さ 2.5 | `runner_end_thk_mm`（None = 上の規則に従う） |

- 傾斜はエッジ帯の肉厚から始まる（帯の幅 0 なら製品エッジで帯の肉厚、そこから t_o へ）
- t_o = 1.0・傾斜なしにすると、円だけが深い形になる
- UI では傾斜の開始位置を「丸端の円の上端に合わせる」（既定 ON、ランナ長と丸端の径に追従）か数値で指定する

### Gate 1 との関係
- Gate 1 の既定値と結果は v0.5.0 と 1 ビットも変わらない（`tests/test_geometry_gate2.py` の指紋で固定）。
  新しい変数の既定（傾斜あり、`runner_ramp_end_mm = 20`、`runner_end_thk_mm = None`）が従来の規則そのもの
- 傾斜の有無・円の深さ・エッジ帯は Gate 1 でも使える。Gate 1 の円の深さは「丸端の円の中を別の肉厚にする」を ON にしたときだけ効く
  （OFF のままなら、深さ 18〜20 の円の上端は従来どおり傾斜の途中の肉厚）

## ランナ Gate 3（逆三角形＋フランク沿いの腕、2026-10-06）
検討資料「12.3型 ゲート形状の見立て」の案 3.3 から起こした形。UI では「Gate 3（逆三角形＋フランク沿いの腕）」、
`runner_shape = "triangle_arms"`、既定値は `GATE3_DEFAULTS`。

### ねらい
Gate 1 の三角は、端へ行くほど浅くて薄い（x=130 で深さ 5、肉厚は最大 1.3）。端の下辺帯へ樹脂が配れない。
中央は今のままにして、フランクに沿って厚い道（腕）を彫り、端まで樹脂を運ぶ。削るだけで作れる。

### 形
- シルエットと肉厚の規則は Gate 1 と同じ（フランク 14°、R12、エッジ帯、傾斜、t_o、円の深さ）
- 腕：両方のフランクに沿って、フランクから**直角に**幅 `arm_w_mm`（既定 9.0）の帯を、肉厚 `arm_thk_mm`（既定 3.5）に彫る
- 腕はエッジ帯の先から丸端の円の手前まで。エッジ帯（ゲートの切り口）と丸端の円の肉厚は変えない
  - エッジ帯の幅を 0（帯なし）にしたときは、製品エッジのすぐ下から腕が始まる。切り口の肉厚が変わらないのは帯があるときの話
- 溝は削るだけなので、腕の中の肉厚は `max(Gate 1 の肉厚, arm_thk)`。今より厚い所は変えない
- 制約：`arm_w < runner_w/2 · sin(flank)`（フランクから、エッジ線上の軸までの距離。既定で 36.3）、`arm_thk > runner_edge_thk`
- 肉盗み（▽）は Gate 1 と同じ規則で置ける。肉盗みは腕の後に削るので、腕と重なる所は肉盗みの厚みになる

### Gate 1 との関係
- 腕の変数（`arm_w_mm` / `arm_thk_mm`）は Gate 1・Gate 2 では効かない。Gate 1 の結果は 1 ビットも変わらない
- UI では Gate 1 の入力欄（フランク角・傾斜・円の深さなど）をそのまま使い、腕の 2 つだけを `fg_g3_*` で足す

## fangate から持ち込まなかったもの
旧ゲート／ウイングゲート／タブ（`gate_type`、`tab_*`、`wing_*`、`old_gate_*`）、井戸・コールドスラッグ・スプルーブッシュ（`well_*`、`slug_*`、`sprue_*`）。
図面のランナは 1 種なので builder は 1 形状に絞り、寸法だけパラメータで振れるようにした（2026-10-06 に Gate 2・Gate 3 を追加）。

## 決定事項
- GitHub は public、顧客名は出さない（リポ名 mold-flow-fangate2、製品は「12.3 インチ プレート」と呼ぶ、図面 PDF はリポに入れない）（2026-09-14）
- fangate のゲート変種は肉盗みだけ残す（2026-09-14）
- Streamlit Community Cloud に配備する（2026-09-14）
- ゲート形状を選べるようにする。客先図面の逆三角形を Gate 1、五角形を Gate 2 とする（2026-10-06）
- Gate 2 の側辺の長さは額縁の下端から測る（2026-10-06、写真の 28 は額縁 20 を除いた値）
- エッジ帯は残し、肉厚と幅を変数にする。幅 0 は帯なし。傾斜はエッジ帯の肉厚から付ける（2026-10-06）
- 円の外の肉厚（t_o）を変数にする。傾斜なしの断面の厚みもこれで決まる（2026-10-06）
- 案 3.3（Gate 1 ＋フランク沿いの腕）を Gate 3 として登録する。腕の幅はフランクから直角に測り、エッジ帯と丸端の円は変えない（2026-10-06）
